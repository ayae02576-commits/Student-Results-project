# Student-Results-project
المشروع هو برنامج بسيط لإدارة درجات الطلاب، بيستقبل اسم الطالب، وثلاث درجات، ونسبة الحضور. بعد كده بيحسب المتوسط، ولو كان في طالب متعسر (متوسط أقل من 50) بنضيف له 5 درجات كرأفة. طريقة الاستخدام افتح ملف index.html في المتصفح، وابدأ تدخل بيانات الطالب واضغط على إضافة طالب، وبعد ما تخلص اضغط تفعيل لجنة الرأفة عشان تشوف التعديل في الدرجات
